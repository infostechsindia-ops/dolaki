## Severity Definitions

1. **P0 - Critical (Release Blocker)**: Data loss, security breach, payment miscalculation, core checkout failure, backend crash.
2. **P1 - High (Release Blocker)**: Vendor order dispatch failure, rider allocation lockup, search engine offline, broken return workflow.
3. **P2 - Medium**: Non-critical UI misalignment, minor reporting discrepancy, non-blocking notification delay.
4. **P3 - Low**: Cosmetic spacing tweak, minor typography size variation, non-blocking documentation typo.
