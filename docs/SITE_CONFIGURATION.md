# AuraMart Commerce OS — Site Configuration Center Guide

## Overview
Centralized configuration management for brand identity, contact details, social links, payment badge assets, and regional defaults.

---

## 1. Configurable Assets
- **Corporate Details**: Legal entity name, VAT registration numbers, corporate headquarters address.
- **Support Contact Info**: Toll-free helpline, support email, operating hours.
- **Regional Profiles**: Market default currency, locale, and phone country code prefix.
