# AuraMart Payment Orchestration & Preview Architecture (CONTENT-005)

## 1. Overview

The Payment Orchestration Engine provides UI selection and backend authorization preview for payment methods without live gateway credentials (`LIVE PRODUCTION DEPLOYMENT: PAUSED`).

---

## 2. Supported Payment Methods (Preview Mode)

- `Credit / Debit Cards` (Visa, MasterCard, RuPay).
- `UPI / Instant Mobile Payment` (Google Pay, PhonePe, Paytm, BHIM).
- `Apple Pay` & `Google Pay` One-Touch Wallet.
- `Cash on Delivery (COD)` (with PIN Code verification).
- `Net Banking` & `No-Cost EMI`.
- `AuraWallet` / Store Credit balance offset.
