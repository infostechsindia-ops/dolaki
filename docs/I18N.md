# AuraMart Internationalization & Multilingual Architecture (CONTENT-010)

## 1. Overview

The Internationalization Engine (`web/src/lib/i18n.ts`) provides multilingual dictionary translations and RTL layout mirroring across English (`en`), Arabic (`ar` with `dir="rtl"`), and Hindi (`hi`).

---

## 2. Language Dictionary Matrix

- `en`: Default English locale.
- `ar`: Arabic (RTL orientation, mirrored navigation, translated buttons).
- `hi`: Hindi (Devanagari script support).
