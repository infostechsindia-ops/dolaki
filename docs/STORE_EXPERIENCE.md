# AuraMart Vendor & Seller Storefront Architecture (CONTENT-007)

## 1. Overview

The Seller Storefront Engine (`web/src/app/seller/[slug]/page.tsx`) provides branded storefront pages for vendor partners.

---

## 2. Storefront Features

- **Store Hero Banner & Verified Badge:** Verified Seller Badge, Response Time rating, Dispatch SLAs, and GSTIN confirmation.
- **Service Ratings:** Packaging rating, Delivery rating, and Product rating breakdown.
- **Follow Seller:** Allows customers to subscribe to seller drop alerts.
- **Store Policies & Warranties:** Easy returns, seller warranties, insured packaging.
- **Store Catalog Filtering:** Category filter tabs, search within store, view mode toggle.
