# AuraMart Commerce OS — Enterprise Navigation Manager Guide

## Overview
Controls multi-level header navigation, mega menu columns, mobile drawer links, and footer links.

---

## 1. Capabilities
- **Hierarchy Tree**: Define parent/child category and link relationships.
- **Link Properties**: Set label, URL endpoint, target window (`_self`/`_blank`), and custom badge text.
- **Instant Deployment**: Update header and footer links across Customer Web and Mobile in real time.
