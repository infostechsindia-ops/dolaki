# Enterprise Merchandising & Campaign Engine Architecture

---

## 1. Merchandising Layout Engine

The storefront uses a Server-Driven UI (SDUI) layout architecture defined in `web/src/data/cmsConfig.ts`. It renders dynamic layout strips:
- **Hero Carousel**: 10 high-resolution promotional banners.
- **Flash Sale Strip**: Hourly countdown timer with discount badges.
- **Flado Quick-Commerce Banner**: Sub-15 minute instant delivery banner.
- **Sponsored Brands Strip**: Official brand logos with offer tags.
- **New Launches**: Product strip featuring newly released SKUs.
- **Curated Lifestyle Collections**: Multi-card collection grid.
- **Studio Lookbook**: Swipeable fashion outfit cards with product tags.
- **Live Deal Card**: Interactive AuraLive deal widget with watcher count.
