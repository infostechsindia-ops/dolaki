# AuraMart Commerce OS — Visual Page Builder Guide

## Overview
Outlines block-based layout composition for marketing campaigns, homepages, and promotional landing pages.

---

## 1. Drag & Drop Features
- Reorder SDUI section cards using `ArrowUp` / `ArrowDown` controls.
- Toggle section visibility, edit section metadata, and bind images via Media Asset Picker.
- Save and publish changes directly to server-authoritative SDUI configuration endpoints (`/api/v1/sdui/homepage` and `/api/v1/sdui/flado`).
