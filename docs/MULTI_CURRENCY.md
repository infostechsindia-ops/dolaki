# AuraMart Multi-Currency Engine Architecture (CONTENT-008 / CONTENT-010)

## 1. Overview

The Multi-Currency Engine supports real-time currency formatting for `INR`, `AED`, `USD`, `EUR`, and `GBP` while preserving 100% server authority for all item pricing, tax, and total calculations.

---

## 2. Supported Currencies & Exchange Rates

- `INR` (Base Currency): `1.0`
- `AED` (United Arab Emirates Dirham): `0.044`
- `USD` (US Dollar): `0.012`
- `EUR` (Euro): `0.011`
- `GBP` (British Pound): `0.0094`
