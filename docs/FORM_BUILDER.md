# AuraMart Commerce OS — Forms Builder & Submissions Guide

## Overview
Enables creation of custom web forms for customer support, merchant onboarding, rider registration, and feedback.

---

## 1. Supported Form Types
- **Customer Support Contact**: Field validation, order ID attachment, category routing.
- **Merchant & Seller Registration**: Tax ID upload, business name, catalog size inputs.
- **Rider Application**: Vehicle type, driver license number, city zone selection.
