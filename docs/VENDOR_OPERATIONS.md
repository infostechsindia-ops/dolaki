# AuraMart Vendor Operations & Order Fulfillment Guide (VENDOR-MOBILE-001)

## 1. Overview

Vendor Operations standardizes the order fulfillment lifecycle across Vendor Portal and Vendor Mobile app interfaces.

---

## 2. Order Kanban Workflow

1. **`NEW`:** Unconfirmed incoming customer orders requiring vendor acceptance.
2. **`ACCEPTED`:** Order accepted by vendor; picking list generated.
3. **`PACKED`:** Items picked and packed into shipping container.
4. **`READY`:** Package ready for delivery rider pickup.
5. **`SHIPPED` / `DISPATCHED`:** Handed over to logistics / delivery rider.
6. **`DELIVERED`:** Order handed over to customer with OTP verification.
